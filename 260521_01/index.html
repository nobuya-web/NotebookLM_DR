超高齢社会におけるシニア雇用の多角的分析と長期的展望

目次
  1. はじめに
  2. 第１章　高年齢者雇用安定法の歴史的変遷と最新の制度改正
  3. 第２章　ステークホルダー間のコンフリクトと「社会的善」に向けた論点整理

本報告書は、少子高齢化が進む日本においてシニア雇用の拡大をマクロ経済の維持に不可欠な「社会的善」と位置づけ、その歴史的変遷から最新の法改正、実務上の課題までを網羅的に分析したものです。主な論点として、2025年の65歳までの雇用確保の完全義務化や、2026年に施行される高齢労働者の労災防止対策の努力義務化といった制度的転換を挙げ、企業には従来の画一的な再雇用から職務ベースの人事制度への移行を求めています。また、人件費負担を懸念する企業と、生活維持や生きがいを求める個人との間にある意識のコンフリクトを構造化し、その調停案として行政によるマッチング支援や助成金の活用を提示しています。最終的には、高齢者を単なる労働力不足の補填ではなく「熟練の人的資本」として捉え直し、安全かつ尊厳を持って働けるエイジフレンドリーな職場環境を構築することが、社会全体のウェルビーイング向上に繋がると結論付けています。

はじめに

はじめに

人口構造の急速な高齢化と生産年齢人口の深刻な減少に直面する日本において、高年齢者の労働力化はマクロ経済の維持と社会保障制度の持続可能性を担保するための国家的な最優先課題である。高年齢者雇用安定法の相次ぐ改正により、企業は従来の「60歳定年」を前提とした雇用管理からの根本的な転換を迫られてきた。

本報告書は、官公庁、東京都、地方自治体、および独立行政法人等の公的機関が発信する統計データや学術調査を基に、シニア雇用の歴史的変遷と最新の制度改正を時系列で整理する。さらに、国、企業、働く個人という異なるアクターが抱える問題意識のコンフリクトを構造化し、それらを調停しながら社会全体のウェルビーイング向上に貢献する「社会的善（Social Good）」としてのシニア雇用のあり方を提示する。本報告書が、企業経営者、人事担当者、サービス開発者、研究者、そして行政担当者にとって、実践的な人事制度改革と政策立案の礎となることを目的とする。

第１章　高年齢者雇用安定法の歴史的変遷と最新の制度改正

1.1 定年・就業年齢引き上げに係る法的規制の歩み

日本の高年齢者雇用政策は、公的年金の支給開始年齢の段階的な引き上げと同調しながら、法的な義務付けのレベルを「努力義務」から「義務」へと段階的に引き上げる形で進展してきた [1, 2]。1971年に制定された「中高年齢者雇用促進法」を全面的に改定する形で、1986年に現在の「高年齢者等の雇用の安定等に関する法律（高年齢者雇用安定法）」が成立した [1, 2, 3]。当時の大半の企業における定年年齢が55歳であった中、同法は60歳定年を初めて「努力義務」として規定した [2]。その後、1998年には60歳未満の定年制が完全に禁止され、60歳定年義務化が確立した [1]。

2000年代以降の法改正は、65歳までの雇用確保と、その先の70歳までの就業機会確保へと軸足を移している [1, 3, 4]。2004年の改正（2006年施行）により、企業は「定年の引き上げ」「継続雇用制度の導入」「定年制の廃止」のいずれかの雇用確保措置を講じることが義務化された [3, 5, 6]。2013年改正では、継続雇用制度を適用する際に対象者を労使協定の基準で選別することを認めず、希望者全員を雇い入れる義務が課されたが、12年間にわたる段階的な経過措置が並行して設けられていた [2, 6, 7]。さらに、2021年4月施行の改正により、70歳までの就業確保措置が「努力義務」として新設された [1, 4]。

1.2 2025年経過措置終了と2026年労働安全衛生法改正のインパクト

2025年4月1日、2013年改正法の12年間にわたる経過措置が満了したことにより、企業におけるシニア雇用の前提条件は一変した [1, 2, 7]。定年を60歳に維持したまま再雇用制度を運用している企業であっても、希望する労働者全員に対して65歳までの雇用機会を確保しなければならなくなった [1, 7]。この経過措置終了は、企業に対し、選別雇用による総人件費の調整という抜け道を完全に塞ぐ形となった [2, 7]。

これに連動して、国は雇用保険法に基づく「高年齢雇用継続給付」の縮小へと踏み切った [1, 7]。高年齢雇用継続給付は、60歳以降の賃金が定年前と比べて75%未満に低下した労働者に対し、公的給付を上乗せすることで雇用の継続を後押しする制度であった [7]。しかし、高齢者雇用が実質的に義務化されたことを踏まえ、2025年4月1日以降に60歳に達した労働者に対する最大支給率は、従来の15%から10%へと縮小された [7]。政府は本給付金について、将来的に廃止する方向で議論を進めており、これまでの「低賃金を国が補填するモデル」から、「企業が自律的に生産性と貢献に見合った賃金制度を設計するモデル」への脱却を急がせている [1, 6, 7]。

さらに、2026年4月1日施行の改正労働安全衛生法は、雇用確保という「量的拡大」から、安全な労働環境の確保という「質的担保」への転換を決定づけた [9, 10, 11]。就労するシニアの急増に伴い、高年齢労働者の労働災害（特に転倒や腰痛）が全国的に頻発しており、全事業者に対して高年齢者の身体特性に配慮した安全衛生対策が努力義務化された [9, 10]。これは、企業に「労働安全衛生管理体制の再構築」と「エイジフレンドリーな職場環境への投資」を促す強い制度的レバレッジとして作用している [10, 11]。

1.3 シニア雇用の量的拡大における実態とデータ分析

厚生労働省が毎年実施している「高年齢者雇用状況等報告（ロクイチ報告）」の提出対象は、常用労働者21人以上の企業237,739社である [12, 13]。最新の令和6年（2024年）集計データによると、65歳までの雇用確保措置を講じている企業は99.9%に達しており、量的な制度導入は飽和状態にある [4, 13]。

しかし、その具体的な実施内容や、努力義務である70歳までの就業確保措置の実施状況を見ると、企業規模や選択する雇用継続のあり方によって大きな偏りが見られる [4, 13]。

第２章　ステークホルダー間のコンフリクトと「社会的善」に向けた論点整理

2.1 国・企業・個人における問題認識のギャップと人事賃金制度の論点

高年齢者雇用をめぐる最大の論点は、政策を推進する「国」、実行を担う「企業」、実際に就労する「個人」の三者間で、問題に対する捉え方と期待される効果が根本的に食い違っている点（コンフリクト）にある [6]。この多角的な立場から生じる不一致を整理することは、制度設計上の最重要課題である [6]。

国はマクロ視点から、年金財政の維持と労働力人口の確保を最優先とし、一律的な就業年齢の引き上げを志向する [5, 6]。これに対し、企業（人事管理層）はミクロ視点から、人件費負担の増加、中堅・若手のモチベーション低下（世代交代の停滞）、そして高年齢者の体力やスキルの個別性の大きさ（一律処遇の難しさ）を懸念する [6]。一方で、個人（シニア労働者）は、低年金による「生活維持」のために働かざるを得ない下位層から、自己実現、健康維持、社会参画としての「生きがい」を重視する上位層まで、就業動機が極めて多元化している [6, 14]。

労働政策研究・研修機構（JILPT）が実施してきた一連の学術調査（No.211, No.198, No.156, No.67）を時系列で比較分析すると、企業が直面する人事管理および賃金決定をめぐる本質的な課題が鮮明になる [6]。

No.211\（2021年公表）2013年改正経過措置期間の総括的実証分析。\・定年延長企業の賃金は、継続雇用企業の賃金より平均「12.8%高い」 [6]。・在職老齢年金や雇用継続給付などの公的補填を考慮して賃金を決定する企業が依然として多い [6]。・「仕事内容を変えない（高齢者の受け入れ拡大優先）」と「被雇用者の仕事満足度（役割変化が必要）」の葛藤 [6]。

JILPT No.211が提示した「企業と個人の利益のコンフリクト」は極めて示唆的である [6]。社会的課題の解決（＝高齢者の受け入れ最大化）という観点からは、60歳以降も仕事内容を変えずに一貫して同一業務に従事させることが合理的である一方、個人の仕事満足度は「定年前後に何らかの仕事の変化や新たな責任の付与があること」によって向上するというトレードオフ関係が実証されている [6]。さらに、高齢期における就業動機やキャリアパスは、55歳時点に所属していた企業の規模や職種といった「現役期前半のキャリア」に強く規定されているという「キャリア格差」の課題も浮き彫りとなった [6]。

この解決の方向性としての「社会的善」は、一律の減給と補助業務への配置転換という従来の再雇用慣行を廃し、年齢に関わらず「職務（ジョブ）の客観的価値と本人のパフォーマンス」に基づいて一貫して評価・賃金を決定する人事制度への全面移行である [6]。定年延長企業の平均賃金が12.8%高いという事実は、年齢ベースの人事管理から職務ベースの人事管理への転換が、高年齢者のモチベーション向上と企業の生産性向上を同時に実現する近道であることを示している [6]。

2.2 高年齢労働者の安全衛生対策とエイジフレンドリーガイドラインの実務

2026年4月1日の改正労働安全衛生法施行は、企業経営に対して単に労働時間を管理するだけでなく、シニアの「身体的脆弱性」に配慮したインフラ整備（安全配慮義務）を実質的に強制することとなった [9, 10, 15]。

60歳以上の高年齢労働者は、加齢に伴う筋力、骨密度、感覚機能（視覚・聴覚）、体温調節機能の低下を免れない [11, 15]。特に小売業・サービス業におけるバックヤードでの「濡れた床、段差による転倒」、製造業や建設業における「重量物の取り扱いによる腰痛」、および過酷な現場環境における「熱中症」は、高齢労災の典型事例である [9, 10, 15]。厚生労働省が策定した「エイジフレンドリーガイドライン」に基づき、企業はハード面、ソフト面、健康管理、教育の4領域で総合的な対策を構築する努力義務を負う [10, 11, 15]。

教育・研修の対策・管理者に対する「加齢による身体・認知特性の理解促進」教育 [11]\・シニア自身に対する正しい荷物の持ち上げ方などの動作指導 [10, 11]\・実現場のカメラ映像を用いた「ヒヤリハット」事例の共有教育 [15]・現場において「無理な作業を強要しない・させない」安全第一のカルチャーが根付く [11]。\・シニア労働者の安全に対するリテラシーが向上する [10, 11]。

これらの一連の対策には、設備投資等の初期コストが必要となるため、中小企業事業主に対しては国が「エイジフレンドリー補助金」を提供している [9, 16]。60歳以上の高年齢労働者を1名以上常時雇用する中小企業であれば、ハード面・ソフト面等での安全環境整備にかかる経費の2分の1（上限100万円等）が国から補助される制度設計となっており、財政面の負担を補填するセーフティネットとして機能している [9, 15, 16]。

2.3 官民による先駆的イニシアチブと具体的事例

高齢者雇用の実効性を高めるため、国や自治体、そして最先端を行く民間企業は、単なる法適合を超えた画期的なイニシアチブを実行に移している [17, 18, 19]。

① 東京都による「シニア就業応援プロジェクト」

東京都は、高齢者が生涯現役としていきいきと活躍できる包摂社会を目指し、行政負担による極めて積極的な事業ポートフォリオを構築している [17, 20]。

東京セカンドキャリア塾・プレシニア（50〜64歳）：210名 [17]\・シニア（65歳以上）：180名 [17]・大学（日本大学、早稲田大学等）のキャンパスを利用した6ヶ月間の無料受講プログラム [17]。\・キャリアデザイン、デジタルスキル、職場体験等の複合的なカリキュラム [17]。・シニアの受講枠は毎年、競争倍率が「5倍以上（300名以上の応募）」に達する人気を誇る [24]。\・修了後、多くの高齢者が就労現場へ復帰している [21]。

東京都の「東京キャリア・トライアル65」は、企業が最も懸念する「能力・健康状態の見極めコスト」を公費（東京都）で完全に引き受けることで、中小企業が高齢者採用へ踏み出す際の心理的・財政的障壁を大幅に引き下げることに成功した極めて完成度の高いスキームである [17, 22, 26]。例えば、同塾で学び直した高齢者が、本トライアル制度を通じて人事管理書類のスキャン化や、ハローワーク申請、テレワーク等のデジタルバックオフィス職として週2日直接雇用され、戦力として定着した事例が報告されている [21]。

② 独立行政法人（JEED）の推進スキーム

国レベルにおいては、独立行政法人 高齢・障害・求職者雇用支援機構（JEED）が「65歳超雇用推進助成金」を軸に、企業の人事制度の「定年撤廃」および「定年引き上げ（70歳以上）」への制度移行を強力にバックアップしている [18, 27]。旧制度が70歳未満であった企業が定年制を廃止した場合、10人以上の高年齢被保険者がいれば、最大240万円の助成金が支給される仕組みである [18, 27]。これは、経営者に対して「年齢による定年という境界線の撤廃」を真剣に検討させる直接的な経済的インセンティブとなっている [18]。

③ 企業における革新的優良事例：グリンリーフ株式会社

令和7年度（2025年）の厚生労働省・JEED共催「高年齢者活躍企業コンテスト」にて最高峰の厚生労働大臣表彰・最優秀賞を受賞したグリンリーフ株式会社（群馬県昭和村、食品製造・農業、従業員126人）は、地方の中小企業におけるシニア雇用のロールモデルである [19, 28, 29, 30]。

同社は定年年齢を「70歳」に設定した上で、70歳以降も「本人の希望があり、かつ自力で通勤（出勤）ができる限り、無制限で雇用を継続する」という画期的な生涯現役制度を就業規則に明文化した [19, 31]。また、同社の強みは制度の設計だけでなく、現場における「チョコ案（小さな改善）」と名付けられたボトムアップ型の改善提案制度にある [19]。シニア労働者を含む現場の声を拾い上げ、昇降機能付き作業台の導入や、通路の段差解消等の細微な作業環境の変更を即座に繰り返し実施した [19, 28]。

これにより、シニアの労働負担は激減し、同時に労働災害防止が達成された [10, 19]。経営陣が掲げる「誰もが主役になれる大家族経営」という組織文化が、シニア自身のエンパワーメントと、外国人労働者や若手への技能伝承の推進に直結している [19, 31]。

まとめ

本報告書で整理してきた高年齢者雇用の歴史的・制度的変遷、および学術的実証結果は、今後の日本の労働市場におけるシニア雇用の成功に向けた重要な示唆を提示している [6, 11]。異なるステークホルダー（企業経営者、人事、サービス事業者、行政）が抱える不一致を、社会的善の追求という共通目的のもとで統合するための指針を以下に示す [6]。

第1に、企業経営者および人事担当者は、2025年4月の経過措置完全終了、高年齢雇用継続給付の減額（将来的な廃止）、および2026年4月の労働安全衛生法改正という一連の法改正を「経営危機」ではなく「戦略的変革の好機」として再定義すべきである [1, 7, 9, 10]。年齢のみを基準とした一律減給と再雇用（嘱託化）による「おざなりの雇用確保」は、シニアの士気を下げるだけでなく、労働災害等の法的・運用的リスクを爆発させる要因となる [6, 15, 32]。職務記述書（ジョブ型人事）に基づく「役割に応じた評価・賃金決定」へと移行し、エイジフレンドリー補助金等の財政的支援手段を活用して職場の物理的安全対策（転倒防止対策、重量物アシスト機器等）を早期に整備することが、安全配慮義務の履行とシニアの労働生産性最大化を両立する道である [6, 9, 15, 16]。

第2に、サービス開発・運営会社の事業責任者にとって、このシニア雇用の全義務化および安全衛生義務化は、巨大なプラットフォーム・新規ビジネスの創出機会である [6, 7, 9]。東京都が主導する「東京キャリア・トライアル65」の成功が実証しているように、企業がシニアを雇用する際の本質的な恐怖は「能力のミスマッチ」と「安全・健康面のリスク」に集約される [6, 17, 22]。シニア求職者を事前に評価し、かつ派遣等の「 de-risk（低リスク化）」スキームを通じて企業側へ繋ぐ人材紹介・マッチング、さらには「企業の現場における労災リスクアセスメント（高齢労働者向けの職場カメラ・AI危険予測等）」を一気通貫で提供するサービスは、今後企業にとって不可欠なインフラとなる [6, 15, 22]。

第3に、国および自治体の担当者は、大企業と中小企業の間でシニア雇用に対する負担能力と実施意欲に大きな非対称性がある点に十分に留意しなければならない [6, 13]。70歳確保措置において、人手不足に喘ぐ中小企業の方が実施率が高い（35.2%）一方で、大企業が慎重（29.5%）であることは、単なる罰則強化が組織の世代交代阻害や若手採用の萎縮という副作用を生みかねないことを示唆している [6, 13]。そのため、画一的な定年70歳への「義務化」を急ぐのではなく、東京都のように「トライアル期間中の公費人件費全額負担」や、JEEDによる「制度移行への大型助成金」といった、「企業の制度移行リスクを徹底的に代替する支援型行政手法」をさらに拡張することが求められる [17, 18, 22]。

最終的に、シニア雇用政策の解決方向性は、「労働力不足を埋めるための高齢者の酷使」であってはならない [14, 26]。労働者本人が「いくつになっても、安全に、自身の尊厳を維持しながら快く能力を発揮でき、それが社会の富の創出と企業の成長に結びつくこと」こそが真の社会的善である [6, 11, 14, 33]。シニアを「衰退する受動的労働力」としてではなく、「成熟した熟練の人的資本」として職場に迎え入れるカルチャーと制度の刷新が、超高齢社会を切り拓く日本のすべての人に繁栄をもたらす礎となる [11, 19]。
